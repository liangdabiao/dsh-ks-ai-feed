# 快手爆款日报

按关键词扫描快手热门作品（默认 AI 词表），按播放量筛选爆款视频、六步智能聚类生成深色主题 HTML 日报，同步输出情报洞察。

## 数据规则

- **更新时间**：每日 15:00 更新前一天数据（≥15 点查昨天，<15 点查前天，工具自动判断；date 支持 `YYYY-MM-DD` 或范围 `YYYY-MM-DD~YYYY-MM-DD`）
- **批量查询**：`keywords` 数组一次传入所有关键词（减少 85%+ API 调用），pageSize 200，photoId 去重，最多 10 页
- **默认关键词组**：AI,人工智能,大模型,GPT,Agent,AI绘画,AI教程

## 鉴权

需要 RedFox API Key（`ak_` 开头，[红狐 hub](https://www.redfox.hk/login) 获取）。优先级：插件配置 > 面板「设置」页 > 环境变量 `REDFOX_API_KEY`。

## 工作流

### 1. 抓取与聚类

`ks_ai(action="fetch")` —— 同步秒回：入库（同关键词组+日期覆盖）+ 固定输出格式（分类概览表 + 情报洞察 4 模块）。

**六步聚类**：泛标签过滤（#AI/#人工智能 等）→ 首标签分组 → 大组 >max(20%,25) 按第二标签二次拆分 → 小组(<3)标签匹配并入已有组 → 过大组(>max(30%,40))用标题高频关键词拆（最多 3 轮）→ 保底 5 分类。组内按播放量降序 TOP5。

### 2. 固定输出格式（强制规范，所有字段不可省略）

```
## 快手爆款日报 · {日期} 日报
**扫描 {N} 条热门视频，聚类 {M} 个分类**
### 分类概览
| 分类 | 数量 | 占比 | 亮点 |
### 情报洞察报告
**一、新兴起量信号**（占比<10% 但均互动>1000 的潜力话题；无则"暂无"）
**二、核心达人**（高产+高互动 TOP5 作者表）
**三、推荐调查方向**（场景+引擎组合+搜索关键词表）
**四、跨平台对比建议**
**日报地址**：{HTML文件路径}
```

### 3. 生成 HTML

`ks_ai(action="html")` —— 深色主题 HTML（快手橙 #ff5000）：分区卡片、封面图、互动数据、视频直链、情报洞察板块。面板可直接查看。

### 4. 深度调查（agent 执行）

用情报洞察里的「推荐调查方向」（场景+引擎组合+搜索关键词）做深挖：技术趋势调查用 DuckDuckGo+Google+Brave、热点事件追踪用 Baidu+Toutiao+Google+WeChat、用户口碑收集用 WeChat+Toutiao+DuckDuckGo+Brave。

### 5. 订阅每日推送

用户要订阅时用 **dsh 定时任务**（schedule_create，target 建议 new_once）：每天 15 点触发，prompt 按「fetch → 固定输出 → html」流程写。**创建前先跟用户确认频率**。

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 未配置 RedFox API Key | 引导到面板「快手爆款日报 → 设置」填写 |
| 3106/3107（Key 错误） | 提示检查 Key |
| 积分不足（3201） | 提示充值地址 |
| 空结果 | 如实说明建议换关键词，不要编造 |
| 目标日期数据未更新 | 建议查最新可用日期（15 点规则会自动回退） |

## 注意事项

- 数值全部来自接口返回，**严禁估算或编造**
- 快手封面图有防盗链，面板/报告已用 `referrerpolicy="no-referrer"` 处理
- 分类由六步聚类决定，**不要预设分类名**

## 在 DSH 插件里使用

- `ks_ai` 工具负责批量抓取/六步聚类/情报洞察/HTML 日报；深度调查与解读由你完成
- `history` 列出日报（新→旧）；补 HTML/读明细传 `reportId`
- 面板可直查关键词组/看分类卡片/情报洞察/生成 HTML；与对话流程共用同一份数据
